# 对齐官方知乎 11.14.0：首页 / 问题回答页 目标规格（v1）

> 依据：真机 Redmi K30 Pro（1080×2400，420dpi，density=2.625）官方 11.14.0 截图 + uiautomator 层级 + APK 资源分析（`reports/official-align/apk-analysis.md`）。
> 换算：`dp = px / 2.625`。截图在 `reports/official-align/screenshots/`：
> `h1.jpg` 官方首页（深色游客态）、`q1.jpg` 官方回答页顶部（问题头+首条回答+吸底条）、`top2.jpg` 回答页顶部完整态、`a1.jpg` 回答列表态、`q4.jpg` 游客阅读上限、`our2.jpg` 我方当前首页基线。
> 官方 11.14 深色实测：页面/卡片/顶栏/底栏统一 `#191B1F`，只有搜索胶囊、banner、chip、评论卡用 `#212429`。

## 0. 范围与非目标

- 必做：**首页**（搜索区、分类 Tab、信息流卡片、底栏）、**问题回答页**（问题头、回答卡、吸底操作条、展开/收起、悬浮控件），颜色/字号/间距/圆角/图标尺寸对齐官方深色与浅色两套。
- 保留项目既有能力：屏蔽/负反馈、阅读器、本地推荐、多账号、设置项、置顶刷新等，不得为了对齐删除用户能力；被官方删掉的元素（如卡片内「不感兴趣 ✕」官方保留，我们保留）按官方截图为准。
- 非目标：不新增官方「看山 / 故事 / 知识 / 圈子 / 领现金」等需要新数据源或新业务的入口。首页 Tab 用项目已有内容源对齐官方视觉结构（见 §2.2）。
- 不改网络协议。游客态改造是独立工作流（另一个任务），本规格只保证 UI 在登录/游客两种身份下都能渲染官方结构。

## 2. 首页目标规格（深色实测量化）

### 2.1 搜索区（高 40dp，水平 16dp）

- 左：当前账号头像 `38dp` 圆形（游客态显示「未登录」占位/登录入口，不显示官方「领现金」，无新业务）。
- 距头像 8dp：搜索胶囊，占满剩余宽度（右 margin 16dp），高 40dp、圆角 20dp、底 `surfaceVariant`，**1.5dp 品牌蓝描边**（官方截图实测 `#1772F6` 2px 描边）。
- 胶囊内部（左→右）：
  - 热词文字 15sp、`onSurface`，`paddingStart = 11dp`；自动轮换热词。
  - 「热」角标：10sp、`#F5533D` 文字 + 1dp 同色描边、圆角 3dp、padding 2×4dp。
  - 竖分隔线 1.5dp × 12dp，颜色 `primary` 50% 透明。
  - 右侧搜索按钮：视觉 `56dp × 30dp`、圆角 15dp、`primary` 底、白字 14sp Bold「搜索」，距胶囊右侧 5dp。
  - 不再有麦克风图标、不再有消息入口（官方把消息放底栏）。
- 点击胶囊/热词 → 搜索页；点击「搜索」→ 搜索页并聚焦输入。
- 顶部 inset：`statusBars` + 0；搜索行高 40dp；下方直接接 Tab 行（无额外分隔线）。

### 2.2 分类 Tab（高 40dp）

- 左对齐、可横向滚动；每项固定 50dp 宽，文字 16sp：选中 Bold + 主色白、下划线 30×3dp 圆角 2dp `primary`，距行底 1dp；未选中 `onSurfaceVariant`。
- 可用内容源：**关注 / 推荐 / 热榜 / 日报**（项目已有，按此顺序；官方「故事/知识/圈子」无数据源，不做）。默认选中「推荐」。
- 右侧固定两个 24dp 图标（官方「频道编辑」「听」）：左侧加 10dp 宽渐变遮罩避免 Tab 文字压图标。
  - 频道编辑：打开底部弹层，可勾选/排序上述 4 个 Tab（复用项目现有偏好存储；至少支持开关，排序可选）。
  - 听：接入项目朗读播放器（若现有 API 不能直接以 feed 队列播放，先打开朗读/播放队列页面；不可用则该图标点击给出提示，禁止假实现）。
- Tab 行下直接是内容区，无分隔线；内容区背景 = `background`。

### 2.3 信息流卡片（扁平、无卡片底/无描边、左右 16dp）

单卡自上而下（深色实测尺寸）：

1. 标题：18sp Bold，最多 2 行，行高 25dp；距卡片顶 13dp。
2. 6dp 间距 → 作者行（高 20.6dp）：头像 20dp 圆 + 8dp 间距 + 作者名 15sp `onSurface`；作者名右侧 8dp：`N 万人关注` 13sp、`#9196A1`（仅当接口返回关注数时展示）。
3. 4dp 间距 → 摘要：15sp/22dp，最多 3 行，`onSurfaceVariant`，末尾省略。
4. 图片区（有图时）：8dp 间距 → 横向可滑，图片高 138dp、宽 138×4/3=184dp、圆角 6dp、间距 4dp；多图圆点/页码指示器放右下角（官方有 1/N 或圆点，按现有实现保留）。
5. 8dp 间距 → 操作行（高 24dp）：`赞同 20dp 图标 + 数字 13sp`、`收藏`、`评论` 三组，组间距按官方起点 16dp/86dp/160dp 对齐（图标 20dp，数字距图标 4dp，数字 `#9196A1`）；行尾（右对齐）24dp「不感兴趣 ✕」。
6. 10dp 间距 → 可选附加块（官方「N 万人正在热议」话题 banner：高 30.5dp、底 `#212429`、圆角 8dp、左侧火焰图标 18dp + 标题 15sp + 右侧「N 万人正在热议」13sp + 箭头）。
7. 卡片间：官方是「上一卡附加块 + 下一卡关注来源标签」紧邻，无分割线；我们保留项目现有的卡片间视觉分隔（0 或 1px 低对比线），但**不得**再出现「圆角卡片浮在更亮页面底」的观感（page 与 card 同色）。
8. 关注来源标签（官方「航海家 @HR凯蒂 已赞同」）：高 22dp、14dp 图标 + 13sp `onSurfaceVariant`，只在有推荐来源字段时展示（项目如无该字段可跳过，不伪造）。
9. 加载骨架必须与上述真实卡同构（标题条 2 行、摘要 3 行、操作行），不得跳版。

### 2.4 底栏（高 60dp + 系统手势 inset）

- 顶部 1px `outlineVariant` 发丝线；底色 `surface`（与页面同色 `#191B1F`/`#FFFFFF`）。
- 5 个等宽槽位（每槽 = 屏宽/5，官方实测 216px=82.3dp；**不要**给整体设 maxWidth 640dp 的居中约束，保持通栏）：
  1. 首页（Home）选中：实心图标 28dp + 12sp 文字主色；未选中：线性图标 + `#9196A1`。
  2. 第二个入口用项目现有内容：**（见下方分工说明，由实现者按现有导航能力选择「关注」或「热榜」并保持官方槽位结构）**
  3. 中间蓝色「＋」：视觉 34×31dp、圆角 10dp、`primary` 底、白色 20dp 加号；点击打开发布面板（复用现有发想法/写回答入口，不新增业务）。
  4. 消息（Notification）
  5. 我的/未登录（Account）：登录态用账号头像 28dp 圆 + 「消息/我的」文字标签；游客态显示「未登录」文字 + 默认人形图标。
- 图标资源：优先项目已有 `ic_vote_*`/底栏图标；官方实心/线性切换规则保留。
- 底栏上方内容区必须留出 48dp 安全边距（官方 `paddingBottom=48dp`），避免最后一张卡被底栏遮住。
- 项目现有「自定义底栏入口」偏好保留：默认值改为上述 5 项；用户改过的配置继续生效（中心＋仅当首页+消息+我的同时存在时展示？实现者按现有架构选择最小侵入方案并在 PR 说明）。

## 3. 问题回答页目标规格

### 3.1 悬浮工具栏（覆盖在内容上）

- 顶部 `statusBars` inset；行高 44dp；左右 10dp/16dp。
- 左：24dp 返回箭头（滚动后可加 48dp 半透明圆形底 `#191B1FCC`）。
- 中部：页面在顶部时显示「邀请回答」按钮（14sp、`primary`、左侧 16dp 人形加号图标；无邀请能力则隐藏/换成问题标题）；滚动后显示问题标题 17sp 单行省略（点击回顶）。
- 右：写回答（60×42dp、14sp、`primary` + 编辑图标）+ 搜索 24dp。
- 滚动时工具栏背景透明，仅图标带圆形底；回到顶部时工具栏下方露出问题头。

### 3.2 问题头（列表首项）

- 顶 inset = 状态栏 + 工具栏 44dp + 16dp。
- 问题标题：22sp Bold / 31dp 行高，最多 3 行，左右 16dp，主色。
- 8dp 间距 → 副信息行：`知乎 · N 个回答 · N 个关注` 13sp `onSurfaceVariant` + 12dp 右箭头（点击问题详情/关注列表，按现有能力）。
- 底部 18dp 间距（官方 header 到第一条回答 44px≈16.7dp）。

### 3.3 回答卡（每条之间 1px 发丝线 + 16dp 上下间距）

自上而下（实测 dp）：

1. 作者行 47.6dp：头像 36dp 圆；作者名 17sp SemiBold；认证/徽章 18dp；签名 13sp `#9196A1`；右侧「+ 关注」胶囊 72×30dp（未关注：`primary` 文字 + `primary` 12% 底；已关注：`onSurfaceVariant` 文字 + `surfaceVariant` 底）+ 分享 24dp。
2. 「N 人赞同了该回答」行 28.6dp：14sp `#9196A1` + 10dp 右箭头；右侧耳机 16dp + 「N 人听过」14sp `primary`（字段缺失则不显示）。
3. 可选「收录于 · 专栏名」chip：高 32dp、圆角 16dp、底 `surfaceVariant`、16dp 蓝色图标 + 14sp `primary` 文字 + 箭头；无字段不渲染。
4. 正文：17sp/24.4dp 行高、主色；段落间距按 Markdown 现有设置；图片满宽、圆角 8dp。
5. 长内容收起：内容区最大高度 = **屏幕可视高度 × 0.618**（官方在列表里是固定高度折叠）；截断处右下角「展开 ⌄」14sp `primary`（或 36dp 圆形箭头按钮，官方两种都有，默认用行内「展开 ⌄」覆盖在最后一行右侧、渐变遮罩 `background` 到透明 24dp 高）；点击后展开全文，展开后可在文末「收起 ⌃」；展开/收起动画 250-300ms ease-in-out。
6. 元信息行 20dp：`YYYY-MM-DD HH:mm · IP 属地 · 禁止转载` 13sp `#9196A1`（按接口返回字段展示，缺失项省略）。
7. 操作行 48dp：
   - 左「欢迎参与讨论」胶囊 132×36dp、圆角 18dp、底 `surfaceVariant`、14sp `#9196A1`（点击打开评论输入）。
   - 右侧 5 组等宽（每组 50.6dp）：赞同 / 反对 / 收藏 / 评论 / 分享；图标 26dp，数字 12sp 在图标上方（赞成/收藏/评论有数字；反对无数字）；图标与数字颜色 `#9196A1`，已赞/已收藏用 `#F05159` / `#FA9D14`。
8. 可选热评卡：高 79dp、左右 16dp、底 `surfaceVariant`、圆角 8dp，头像 20dp + 昵称 13sp + 评论内容 14sp 2 行省略 + 右侧点赞 12sp；仅当接口返回热评时展示。
9. 卡片间：1px `outlineVariant` 通栏分隔 + 上下 16dp 留白（官方实测分隔线上下各约 16-21px）。
10. 「下一个回答」预露出：不额外留白，列表自然连续。

### 3.4 吸底操作条（关键交互）

- 高 48dp + 顶部 1px 发丝线；底 `surface`；左右 16dp。
- 内容：左 32dp 头像 + 作者名 15sp + 「关注」13sp `primary`（132dp 宽区域）；右侧 赞同/反对/收藏/评论/分享 5 组，图标 26dp，数字 12sp 在图标上方，颜色同卡片操作行。
- 显示规则：**当前正在阅读的回答**其卡片内操作行滚出屏幕后固定显示，滚回可见时隐藏（用滚动位置与当前 answer index 判定；滚动方向不改变规则）。点击与当前回答联动；游客态点击触发登录提示（由游客任务处理，UI 预留回调）。
- 「下一篇内容」悬浮按钮：36dp 圆形底 + 下箭头，右侧 16dp，位于吸底条上方 16dp；点击滚动到下一条回答开头。

### 3.5 游客阅读上限（UI 预留，不做业务）

- 列表末尾版权/上限块：高 119dp，居中一行「登录查看更多精彩回答」17sp `primary` + 右侧 16dp 箭头；点击进入登录页。仅当业务层返回「游客已达上限」时渲染（游客任务提供状态；无状态不显示）。

### 3.6 交互保留

- 上下滑动切换回答（项目 `AnswerVerticalOverscroll` 能力保留，但视觉改为官方连续列表形态；如与官方连续列表冲突，以官方列表 + 吸底条为准，切换回答手势降级为普通滚动）。
- 评论、收藏、分享、屏蔽、阅读全文、双击点赞等既有能力全部保留，入口位置按官方布局重排。
- 展开态回到收起态时滚动位置稳定在展开按钮附近。

## 4. 验证方式（实现者自测 + Lead 真机验收）

1. `./gradlew :app:assembleLiteDebug` 必须通过；`./gradlew ktlintFormat` 后无格式问题。
2. 改动文件内不得留下未使用 token/组件；不得新增依赖。
3. 真机（`com.github.zly2006.zhplus.lite`，已登录，覆盖安装 `adb install -r`）截图对比：
   - 首页深色：搜索区/ Tab / 卡片 / 底栏逐项截图与 `screenshots/h1.jpg` 并排核对；像素颜色用 `#191B1F`、`#212429`、`#1772F6`（浅色）与 `#558EFF`（深色）抽查。
   - 回答页深色：问题头 / 回答卡 / 操作行 / 吸底条对照 `screenshots/top2.jpg`、`a1.jpg`。
   - 浅色模式同样抽查（可临时切系统深浅色）。
4. 布局矩阵：宽 411dp（本机）、大字号（系统字体放大 1.15x）、深/浅色，元素不得溢出或换行错位。
5. 既有测试：`shared` 里引用旧令牌（如 `ZhihuTypography.FeedTitle` 尺寸断言、`DesignSystemTokensTest`、`ThemeContrastTest`）需要同步更新断言；不得为了让测试通过而保留旧视觉。
